? What Schema level security controls:
- CREATE: Put object like "table"/"functions" in the schema.
- USAGE: Look in the schema and see what is present.

? Check the roles have create & usage permission in public schema
SELECT nspname AS schema,
       pg_roles.rolname AS role,
       has_schema_privilege(pg_roles.rolname, nspname, 'USAGE') AS usage,
       has_schema_privilege(pg_roles.rolname, nspname, 'CREATE') AS create
FROM pg_namespace
CROSS JOIN pg_roles
WHERE nspname = 'public';
