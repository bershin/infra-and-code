? What does instance level security controls
Instance level security controls: 
- login
- create database/roles

? Permissions applied in instance level
SUPERUSER - can do anything (NOSUPERUSER)
CREATEDB - make databases
CREATEROLE - make more role
LOGIN - can login into database
REPLICATION - can be used for replication.

? PostgreSQL privileges are additive (permissive), not restrictive, explain
- If CREATEDB permission is given in group level and NOCREATEDB is given in user level. Still the user will be able to create database as it inherits permission.
- If user added to group have NOCREATEDB, user can't create DB. If he is added to one more group which has CREATEDB. He will be able to create db.

# Check role and its members
SELECT
    r.rolname AS role_name,
    m.rolname AS member_name
FROM
    pg_auth_members am
JOIN pg_roles r ON am.roleid = r.oid
JOIN pg_roles m ON am.member = m.oid
ORDER BY role_name;
