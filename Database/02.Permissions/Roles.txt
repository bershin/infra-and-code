Roles is alias for User & Group
Roles resides in the instance level.
Roles needs to be nested
- Create a generic role(hr, sales) that can't login and create role with login and & them to the generic role.

=== Instance level(All database) login, create database/roles.
SUPERUSER - can do anything (NO)
CREATEDB - make databases
CREATEROLE - make more role
LOGIN - can login into database
REPLICATION - can be used for replication.

CREATE ROLE hr NOSUPERUSER NOCREATEDB NOLOGIN;
CREATE ROLE accounting NOSUPERUSER NOCREATEDB NOLOGIN;

# See the roles of the specific users
SELECT rolname, rolsuper, rolcreatedb, rolcanlogin
FROM pg_roles
WHERE rolname IN ('hr', 'accounting');

=== Schema level(Create & use particular schema)
REVOKE ALL ON SCHEMA public FROM public;

northwind=> CREATE SCHEMA suzy;
<permission error>

GRANT CREATE ON DATABASE northwind TO accounting;
northwind=> CREATE SCHEMA suzy;
<Success>

northwind=> CREATE table can_i (id int);
DROP TABLE can_i

REVOKE ALL ON SCHEMA public FROM public;
northwind=> CREATE table public.can_i (id int);

GRANT CREATE ON SCHEMA public TO accounting;
GRANT USAGE ON SCHEMA public TO accounting;

=== Table level(What Operation to be performed on a table)
Control:
- SELECT(read rows in table)
- INSERT(write data to table)
- UPDTAE(change data in table)
- DELETE(delete data)
- TRUNCATE(remove all data at once)
- REFERENCE(allows user to create foreign key constraints)
- TRIGGER(create triggers on table)

GRANT SELECT ON ALL TABLES IN SCHEMA public TO accounting;
GRANT SELECT ON TABLE employees TO hr;
GRANT INSERT ON TABLE employees TO hr;
GRANT UPDATE ON TABLE employees TO hr;
=== Column level(What Operation to be performed on a specific column)
Control:
- SELECT(read the column)
- INSERT(insert data into column)
- UPDTAE(update data in column)
- REFERENCE(permission to refer to a column in foreign keys)

susy@northwind=> SELECT * FROM employees;

=== Row level(Which rows in database can you perform operations on)

ALTER TABLE orders
ENABLE ROW LEVEL SECURITY;

susy@north=> SELECT COUNT(*) FROM orders;

CREATE POLICY accounting_orders ON orders
FOR SELECT
TO accounting
USING (orderdate >= '1998-01-01');
