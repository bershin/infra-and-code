===Install python and pip(package manager for python):
Download: https://www.python.org/

check:
$ python --version

$ pip --version
# Package to make http request
$ pip install requests
$ pip show requests
$ pip list

===Setup virtual environment:
$ pip install virtualenv(older version)
Create virtual environment(bjohnenv, is my environment):
$ python -m venv bjohnenv
# Activate the environment
$ source bjohnenv/bin/activate
$ pip list
$ pip install requests
$ pip list
$ pip freeze > requirements.txt
$ deactivate
