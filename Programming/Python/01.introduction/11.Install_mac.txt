Priority order pyenv follows:
	1.	Shell override (pyenv shell) → highest priority.
	2.	Local version file (.python-version) → project-specific.
        - cd ..; rm .python-version
	3.	Global version (pyenv global) → default for user.
        - pyenv global 3.12.9
        - > ~/.pyenv/version
	4.	System Python → fallback if nothing else is set.
