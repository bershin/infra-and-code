===Setup virtual environment:
#####$ pip install virtualenv(older version <3.3)
- Special tool in Python that helps you to manage different dependencies for your projects in isolated environments without using virtual environments.
- Every package you install affects all of the projects on your computer. This can lead to conflicts when one project needs a specific version, while another requires a different one.

# Create virtual environment(bjohnenv, is my environment):
$ python -m venv bjohnenv
# Activate the environment
$ source bjohnenv/bin/activate
$ pip list
$ pip install requests
$ pip list
$ pip freeze > requirements.txt
$ deactivate
